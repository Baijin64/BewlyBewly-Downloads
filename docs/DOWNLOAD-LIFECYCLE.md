# 后台启动与退出

扩展 0.44.6 与助手 0.2.8 将浏览器界面和本地下载服务的生命周期分开。

## 使用行为

- 普通 BV / AV / 视频链接的解析、规格选择、文件名预览，以及最近的配置和任务记录，可直接在浏览器展示，不启动 Node 下载服务或 aria2。
- 点击下载、加入待下载、修改本地配置、使用本地文件或工具时才连接助手。首次显示扩展内的启动确认；同意后保存选择，可在下载设置撤回。
- 按需会话没有正在执行的下载、混流、附件、工具或本地请求后，空闲约 5 秒退出。队列中只有待下载、暂停或失败任务时也可退出，记录保存在 SQLite，下一次操作时恢复。
- 自动关机倒计时期间服务保持运行，可从托盘取消。关闭浏览器不会中断正在下载的任务。
- Windows 开始菜单手动打开助手会进入常驻模式，复用已有服务而不增加第二个后台。仍遵守“Windows 手动启动后的空闲退出”设置，默认不自动退出。
- 托盘随服务启动，显示“按需”或“常驻”，服务退出时一起清理。需要持续监听剪贴板时使用 Windows 手动启动。

Native Messaging 本身没有每次启动的系统授权弹窗，这里的确认由扩展提供。新增行为没有增加浏览器权限。短链接展开和本地辅助工具仍可能需要临时唤起助手。

## 快照与同步

权威记录仍是 `%LOCALAPPDATA%/BewlyDownload/downloads.sqlite`。服务把可展示的配置和最近最多 200 条任务写入 `ui-snapshot.json`；扩展缓存最近记录，助手未运行时显示同步时间。快照不包含 Cookie、DPAPI 会话、RPC 凭据或准备好的媒体下载地址。

第一次升级同步可能短暂启动原生连接器读取快照，这段操作由 C# 完成，不需要 Node 或下载服务。“刷新 / 检查连接”只探测已经运行的服务，服务未运行则读取最新快照；不会为了刷新历史启动下载后台。浏览器工作线程重启后，有活动任务时会被动重新连接已有服务。

显示的离线列表是最近同步的快照，并非实时查询所有磁盘记录；助手连接后恢复数据库分页与完整操作。快照写入失败不影响已接收的下载。

## 验证

111 项前端测试覆盖首次确认、取消、只读界面、缓存失败、工作线程重连、批量移除同步及通信释放；49 项原生测试覆盖实际进程启动、持续轮询时空闲退出、队列持久化、Windows 手动启动复用，以及超过空闲时限的下载不会被误杀。

本机 MSIX 使用隔离目录验证系统 Node、FFmpeg、aria2。缺 Node 环境完整 UAC/MSI 安装和真实慢网/CDN 切换仍沿用此前的待验收范围。
