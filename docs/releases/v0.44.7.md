# 个人维护测试版 0.44.7（助手 0.3.0）

下载助手完成纯 Rust 重写，不再依赖 Node.js 或 aria2，并补齐了 Windows 外观、暂停/恢复响应以及 Android 独立客户端：

- **纯 Rust 下载引擎（助手 0.3.0）**：`bewly-core` / `bewly-engine` / `bewly-service` / `bewly-store` / `bewly-media` / `bewly-host` 全量接管分片下载、断点续传（兼容 `.aria2`）、WBI 签名、SQLite/LevelDB 迁移、`.bilidownexport` 历史导入导出及回环 RPC 服务。
- **内置精简版 LGPL FFmpeg**：Windows MSIX 内置 `bin\ffmpeg.exe`，Android 端通过 `jniLibs/<abi>/libffmpeg.so` 随包分发，开箱支持 DASH 合流、提取音频与 MP3 转码。
- **更快的暂停/恢复与空闲退出同步**：
  - 下载引擎按 64 KiB 切片检查取消标记，弱网下暂停不再等待整个 1 MiB 分片读完；
  - 修复暂停后立刻恢复时旧运行线程回写 `paused` 覆盖恢复状态的竞态问题；
  - 扩展端在助手空闲退出后能正确同步目录选择结果、配置缓存与任务标签页。
- **Windows 图标与 NativeAOT 托盘**：`BewlyDownloadHost.exe` 与 `BewlyDownloadTray.exe` 启用 Bewly 图标与吉祥物绘制。
- **Android 独立客户端（0.44.7）**：重做主界面并新增设置页、辅助工具页、B 站 WebView 登录弹窗、MediaStore 导出与优雅停服 JNI 入口。

扩展 **0.44.7** 建议配合助手 **0.3.0** 使用，旧版 SQLite 数据库与设置会自动沿用。推荐加载解压后的 Chrome ZIP；详情见 [安装说明](../INSTALL-DOWNLOADS.md)、[平台支持](../PLATFORMS.md) 与 [构建说明](../BUILD-DOWNLOADS.md)。
