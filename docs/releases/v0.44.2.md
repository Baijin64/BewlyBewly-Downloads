# 个人维护测试版 0.44.2

主要供维护者和身边朋友使用。扩展 0.44.2，Windows 本地连接器 0.2.6。

## 来源与致谢

- BewlyBewly 原项目：[BewlyBewly/BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)，原作者 [Hakadao](https://github.com/hakadao)。保留 MIT 许可证与上游署名。
- Bilidown 原作者：[王子周棋洛的主页](https://zhouql.vip/)。下载行为与配置参考原 Bilidown，本地下载核心在本分支中重新实现。
- 这是个人维护分支，不是上述项目的官方续作。

## 功能

- 视频页与主页卡片菜单直接下载，Dock 下载器管理持久队列、批量任务与合集/分 P。
- 画质、音质、编码、并发、命名与目录规则；视频、原生音频、MP3、封面、弹幕、字幕及 NFO。
- Bewly 主题按钮、开关和圆角进度条，显示当前视频/音频阶段、暂停进度及媒体处理中状态。
- 独立 Windows 服务与托盘；连接器不内置 Node.js，复用系统 Node，缺少时提供本地下载安装入口。
- 保留原生配置和历史的可选迁移、辅助转换工具及已实现的播放优化。

## 安装与限制

推荐使用 Chrome ZIP，解压后在 Chrome/Edge 开发者模式加载。CRX 文件签名通过，但不保证浏览器允许直接安装并启用，未声称已解决非商店 CRX 限制。

连接器 MSIX 使用本机开发证书签名，其他电脑需手动信任随包公开证书。私钥没有上传。GitHub Actions 提供的 unsigned MSIX 仅用于构建验收；Releases 的签名 MSIX 可用于个人测试安装。

慢网/CDN 线路切换、缺 Node 机器上的完整 UAC/MSI 交互仍待单独验收。AI/MCP 留到后续。详细步骤见仓库的安装及构建说明。
