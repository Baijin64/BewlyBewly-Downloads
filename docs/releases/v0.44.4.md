# 个人维护测试版 0.44.4

修复从旧 Bilidown 导入后历史封面缺失：旧记录的 `pic` 现在保留为 `cover`，重新导入同一份历史也能补回缺失封面。已有记录、完成时间、文件目录和原有封面保持不变，不会新增重复下载任务。迁移完成提示会显示补回的封面数量。

扩展 **0.44.4**，本地连接器 **0.2.7**。本轮已在维护者电脑对现有 17 条历史记录完成封面恢复，17 个图片请求均返回成功；其他电脑使用新连接器重新导入原历史导出文件即可补回其中保存的封面。

本地验证：76 项前端测试、42 项原生测试、应用 ESLint 和 Vue 类型检查通过。新安装包继续复用系统 Node.js，不包含 Node 运行时；FFmpeg、aria2 保持现有版本。推荐使用扩展 ZIP 解压加载；CRX 分发限制的验证范围不变。
