# 个人维护测试版 0.44.5

优化推荐请求、悬停预览缓存和卡片更新开销，保留原 UI、布局、菜单和播放操作：

- 重复触底合并、限制自动补页，失败后停止；刷新或离开页面会取消旧请求，避免旧结果回写。
- 视频资料与预览使用有上限的内存缓存；限制预览并发，账号变化时清理，推荐结果保持实时。
- 稳定卡片属性并复用原卡片，后续封面延后加载、异步解码。300 条追加到 330 条的测试中，原有 300 张卡片没有新增渲染。

98 项前端测试、42 项原生测试通过，应用 ESLint 与 Vue 类型检查通过。CSS 归一化 Vue 作用域标识后与上一版一致，浏览器权限未新增。真实慢网/CDN 切换仍沿用此前的待验收范围，不承诺媒体下载速度的固定提升。

扩展更新为 **0.44.5**，助手保持 **0.2.7**。已有用户只需重载扩展、刷新 B 站，不必重装助手。继续下载 MP4 后使用系统播放器；不增加离线播放界面。

本机构建已独立于旧 Bilidown 安装目录。旧程序按用户要求移至回收站，视频和下载记录保留。安装后的 MSIX/ZIP 可以清理，浏览器实际加载的解压扩展目录需保留。
