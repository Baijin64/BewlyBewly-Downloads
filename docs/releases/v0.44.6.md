# 个人维护测试版 0.44.6

下载界面和本地服务分离，降低平时的后台占用：

- 点击下载入口先展示界面，使用最近配置与记录，不为查看界面启动下载服务。
- 实际下载、加入待下载或本地操作首次确认后唤起助手；处理结束后约 5 秒自动退出，下载引擎、托盘和通信进程随之结束。
- 待下载和暂停任务保存在磁盘，退出后不丢失；关闭浏览器后正在执行的下载继续。
- 从 Windows 手动打开助手会保持常驻，复用已有进程；原手动空闲退出设置保留。

扩展 **0.44.6** 需要同步更新助手 **0.2.8**，然后重载扩展、刷新 B 站。111 项前端测试、49 项原生测试通过。提供 Chrome ZIP、签名候选 CRX 和 Windows MSIX；CRX 直接安装启用仍取决于浏览器分发限制，推荐加载解压 ZIP。
